# Feel The AGI

An interactive museum and time capsule of the scaling era, built with Astro 7 from a hand-curated archive of 1,483 tweets.

## Features

- Reverse-chronological, earliest-first, and randomized reading modes
- Search and year filters
- Faithful tweet attribution, quote posts, media, links, and source URLs
- Responsive dark and light themes
- Progressive rendering for a fast initial load

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The static production output is written to `dist/`.
